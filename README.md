
O jogo é um dungeon-crawler inspirado pelo clássico Nethack, e pelo primogénio deste estilo de jogo, Rogue.

O jogo consiste em explorar uma masmorra repleta de tesouro e de monstros perigosos. O objetivo é chegar ao nível mais profundo possível, onde os tesouros são mais valiosos, contudo os monstros são cada vez mais assustadores.

O combate, tal como em NetHack, é inspirado pelo RPG de mesa Dungeons and Dragons Advanced 2e. Como tal, quando atacando um monstro (ou sendo atacado), o jogo 'rola um dado de 20 faces', caso o valor no mesmo seja maior que a armour class (representa armadura, capacidade de esquivar do ataque, etc) de quem esta a ser atacado, o ataque tem sucesso, caso contrário, não acerta o alvo. 

Para compilar deve ser usados os seguindes comandos por ordem:
-  make clean
- make rogue
- make run

Para jogar devem ser usadas as setas do teclado, o enter quando no menu principal/menu de pausa para selecionar a opção desejada e p/P para consumir uma poção, caso esteja alguma no inventário do jogador. Para pausar o jogo ou sair, deve ser usada a tecla esc e selecionada a opção pretendida.
